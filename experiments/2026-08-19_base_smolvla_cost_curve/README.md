# Кост-кривая с голого smolvla_base (абляция претрена)

Дата: 2026-08-19. Вопрос: **сколько демонстраций стоит наш libero_90-претрен?**
Та же кост-кривая k=1/2/3/5/10/25, но каждая адаптация стартует не с претрена,
а с **голого `lerobot/smolvla_base@c83c3163`** (community-претрен на реальном
SO-100; LIBERO/Franka не видел) через schema-адаптированный снапшот, с
которого начинался и наш претрен. Разрыв между этой кривой и замороженной
претрен-кривой = ценность in-domain претрена, выраженная в демо.

Рецепт байт-в-байт как у претрен-кривой: expert-only (vision+VLM заморожены),
2000 шагов, batch 32, fp32, seed 1000, демо = официальные demo_0..demo_{k−1},
независимая адаптация на каждую пару (задача, бюджет); eval тем же харнесом
(20 эпизодов, все видео на диск). Точки k=0 нет по построению: проекции
state/action инициализируются только при файнтюне — «zero-shot» голого base
шёл бы через случайные проекции. Итого 60 тренировок + 60 evals на GPU 0–3.

Предсказания и правила R1bc–R4bc записаны до запуска:
[reports/PRIOR_EXPECTATION.md](reports/PRIOR_EXPECTATION.md). Ожидание-заголовок:
претрен стоит >25 демо/задачу в низкобюджетном режиме (base при k=25 не
догонит претрен при k=1).

## Запуск

```bash
cd experiments/2026-08-19_base_smolvla_cost_curve
scripts/prepare.sh    # манифест базового чекпойнта + селекция эпизодов
scripts/audit.sh      # аудит заморозки параметров ДО тренировок
scripts/run_all.sh    # оркестратор: 60 train + 60 eval на GPU 0-3
scripts/aggregate.sh  # кривая + оверлей замороженного претрен-референса
```
