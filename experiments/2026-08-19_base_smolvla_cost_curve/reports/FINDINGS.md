## Главный вывод: предобучение на libero_90 практически ничего не дает, как только k >= 1

| среднее по 10 | k=1 | k=2 | k=3 | k=5 | k=10 | k=25 |
|---|---:|---:|---:|---:|---:|---:|
| обычный smolvla_base | 0.485 | 0.660 | 0.690 | 0.745 | 0.865 | 0.790 |
| предобучение libero_90 (замороженный эталон) | 0.550 | 0.705 | 0.780 | 0.830 | 0.875 | 0.850 |
| разрыв | −0.065 | −0.045 | −0.090 | −0.085 | −0.010 | −0.060 |

Задачи 0–2: база 0.550/0.717/0.850/0.883/0.933/0.883 — при k=3 база даже ПРЕВОСХОДИТ эталон (0.850 против 0.717; одно начальное значение (seed), в пределах шума).

- **Прогнозы 1–3 решительно опровергнуты.** Прогнозируемый базовый показатель при k=1 составлял 0.00–0.05; измеренный — 0.485. Разрыв в воплощении/домене (реальный SO-100 -> симулированный Franka) не помешал адаптации только с участием эксперта (expert-only) даже на основе ВСЕГО ОДНОЙ демонстрации.
- **R1bc («предобучение эквивалентно > 25 демонстрациям») — не срабатывает**, причем впечатляюще: база при k=1 уже превосходит то, чего правило требовало от базы достичь к k=25.
- **R2bc срабатывает за рамками собственной предпосылки**: база находится в пределах 0.1 от предобученной кривой при ЛЮБОМ бюджете, а не только при k >= 10. При данном рецепте измеримая ценность внутридоменного предобучения при k >= 1 составляет ~0.05–0.09 успеха, концентрируясь на низких k, а его единственным однозначным вкладом является точка k=0 (для zero-shot с результатом 0.005 ТРЕБУЕТСЯ некоторое внутридоменное обучение; у базы точка k=0 вообще не определена).
- Спад при k=25 воспроизводится и на базе (0.865 -> 0.790), отражая немонотонность эталонной кривой — это согласуется с гипотезой о недостаточном обучении при фиксированных 2000 шагах, а не с какими-либо особенностями предобучения.

## Интерпретация

Основную работу выполняют универсальные функции VLM/зрения smolvla_base plus переобучение эксперта действий (~100 млн параметров) на целевых демонстрациях; 90 задач внутридоменного предобучения LIBERO добавляют мало по сравнению с тем, что дает одна целевая демонстрация. Это согласуется с диагностическими тестами: язык в любом случае представляет собой селектор точных строк, перенастраиваемый с помощью тонкой настройки, а выполнение со стороны сцены адаптируется на основе целевых кадров — и то, и другое k >= 1 предоставляет напрямую.

## Выводы для итогового отчета

1. Крутизна кривой затрат является свойством smolvla_base + рецепта обучения, а не нашего предобучения; в отчетах нельзя приписывать результаты при низких k влиянию внутридоменного предобучения.
2. Методы Задачи 2, построенные на совместном обучении на наблюдаемых данных (извлечение/переразметка), теперь должны превзойти более сильную нулевую гипотезу: «просто настроить базу на k демонстрациях». Их ценностное предложение сужается до k=0 и остаточного разрыва ~0.05–0.09 при низких k.
3. Положительное позиционирование для Задачи 5: 1 демонстрация + 2000 шагов только для эксперта ≈ 0.5 успеха на отложенном LIBERO-Goal на основе универсальной базы — именно адаптация с малым числом примеров (few-shot), а не предобучение, является ключевым ресурсом.

## Ограничения

- Одно начальное значение обучения (seed) на обеих кривых (требование задания о двух начальных значениях пока не выполнено); шум оценки не зафиксирован для каждого эпизода (по проекту используется общий тестовый стенд с эталоном; доверительные интервалы Уилсона покрывают это).
- Рецепт только для эксперта (expert-only) с фиксированными 2000 шагами; выводы сделаны «при данном рецепте» (последующее размораживание R3bc не имеет значения ввиду высоких результатов, но анализ влияния количества шагов остается актуальным для спада при k=25).
- Совместное планирование (3 задачи на GPU) заявлено в протоколе; команды для каждой задачи идентичны эталонным.
