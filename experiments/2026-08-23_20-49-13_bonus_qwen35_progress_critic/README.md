# Бонус B: критик прогресса на базе Qwen3.5-4B

Этот изолированный эксперимент реализует только этапы 1–6 подготовки в рамках Бонуса B. Он разработан для обучения сигнала видеопрогресса на канонических экспертных видеозаписях LIBERO-90 и резервирует полные инструкции задач для валидации. Эксперимент намеренно не содержит ранжирования чекпоинтов, логического вывода Robometer и оптимизации политики.

## Протокол

- Базовая модель: `Qwen/Qwen3.5-4B@851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a`.
- Входные данные: точная инструкция LIBERO и четыре хронологических кадра с верхней камеры, выбранные из префикса траектории.
- Целевая переменная: абсолютный прогресс конечной точки, дискретизированный на 32 одинаковых бина.
- Голова (head): один линейный 32-биновый классификатор на финальном скрытом состоянии промпта.
- Адаптация: LoRA r=32, alpha=64 на языковой основе; замороженный кодировщик зрения (vision encoder).
- Без головы предпочтений, головы успеха, неудачных траекторий, аугментации перемотки, ранжирования или сравнения с Robometer.
- Данные: только канонический официальный LIBERO-90 с поворотом rot180. Подтверждено отсутствие трех задач LIBERO-Goal из задания.
- Разделение (split): детерминированное по полной естественно-языковой инструкции задачи, seed 1000, 10% отложено для валидации.
- Градиентный чекпоинтинг (gradient checkpointing): явно отключен. Нехватка памяти (OOM) должна в первую очередь устраняться уменьшением размера батча на устройство.

Модель имеет размер 4B, поэтому с научной точки зрения это собственный критик 4B, а не буквально «малый критик» из задания. Это ограничение должно быть раскрыто в финальном отчете по бонусу.

## Реализованные этапы 1–6

1. Фиксация базовой ревизии Qwen3.5-4B и протокола, ориентированного только на прогресс.
2. Валидация канонической конверсии LIBERO-90 и построение манифеста эпизодов.
3. Создание детерминированного разделения на обучение/валидацию без пересечения задач с seed 1000.
4. Декодирование четырех хронологических кадров префикса и присвоение нормализованного бина прогресса конечной точки.
5. Реализация обучения LoRA, аудита замороженного зрения, фиксированной валидации, построения графиков потерь, логирования в Trackio и сохранения чекпоинтов адаптера/головы.
6. Предоставление точек входа для дымового теста данных на GPU-0 и бенчмарка на 50 шагов, включая прогнозирование времени выполнения полного запуска без фактического старта задачи на 2000 шагов.

Ранжирование чекпоинтов, оценка Robometer и оптимизация политики находятся за рамками данного эксперимента.

## Команды

```bash
cd /vla_test/experiments/2026-08-23_20-49-13_bonus_qwen35_progress_critic
source scripts/common_env.sh

# Валидация канонического набора данных и запись манифеста разделения на уровне задач.
scripts/prepare.sh

# Декодирование реальных клипов обучения/валидации и запись обзорной контактной ленты.
scripts/smoke_data.sh

# Сфокусированные тесты.
pytest -q

# Инженерный бенчмарк на GPU-0: 50 шагов оптимизатора и валидация на шагах 0/25/50.
# Планировщик LR сохраняет заявленный горизонт в 2000 шагов.
scripts/benchmark_50.sh
```

Бенчмарк записывает:

- `results/benchmark_50/metrics.jsonl`;
- `results/benchmark_50/loss_curve.png` с потерями обучения и валидации;
- `results/benchmark_50/summary.json` со скоростью, пиковым объемом VRAM и ожидаемым временем выполнения (ETA) для 2000 шагов;
- `artifacts/trainable_parameters.json` с аудитом LoRA/замороженных параметров.

Полный запуск был успешно завершен на физическом GPU 0 23.08.2026 с использованием зафиксированного протокола:

```bash
scripts/launch_full.sh
```

Он выполняет 2000 шагов оптимизатора, оценивает фиксированное подмножество валидации каждые 100 шагов и сохраняет чекпоинты адаптера/головы каждые 200 шагов. Состояние выполнения, PID процесса, метрики и логи находятся в `results/status.json`, `results/train_full.pid`, `results/training/metrics.jsonl` и `results/logs/train_full.log` соответственно.

Обучение завершило все 2000 шагов за 48.25 минуты. Кросс-энтропия валидации улучшилась с 5.087 на шаге 0 до наилучшего значения 2.196 на шаге 1300 и завершилась на уровне 2.216. Финальный чекпоинт: `results/training/checkpoints/002000`; см. `reports/TRAINING.md`.

Все сгенерированные артефакты дымового теста данных и бенчмарка на 50 шагов были удалены 23.08.2026 по запросу пользователя. Запуск соответствующих команд воссоздаст их на основе зафиксированного протокола.
