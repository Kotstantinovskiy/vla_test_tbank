# Проприоцептивный шум с высоким значением alpha при k=1, 1000 шагов обучения

Каждая адаптация пары (задача, alpha) представляет собой независимый полный файнтюнинг закрепленной предобученной модели на официальной демонстрации `demo_0` соответствующей задачи, с добавлением аддитивного гауссовского шума с нулевым средним `alpha * eps`, который применяется к нормализованному проприоцептивному состоянию внутри функции `policy.forward` только во время обучения (состояние (STATE) нормализуется по среднему и стандартному отклонению (MEAN_STD), поэтому в исходных единицах alpha соответствует величине sigma_i = alpha * Std(s_i)).
Бюджет обучения сокращен вдвое по сравнению с первым проходом: 1000 шагов с пропорционально сжатым автоматически масштабируемым графиком скорости обучения (LR schedule); таким образом, ветвь alpha=0.00 при 1000 шагах является единственным валидным базовым решением (baseline) внутри эксперимента.
Действия и изображения не изменяются; при оценке (n_action_steps=50, 20 эпизодов, банк сидов 1000..1019) шум не применяется. alpha=0.00 является контрольной группой внутри эксперимента (строгое отсутствие операции, рецепт full-FT при k=1).
