# Analyst: общая кост-кривая бейзлайна и AUC

Дата: 2026-08-18. Аналитический эксперимент без rollouts и обучения:
собирает полную кривую наивного бейзлайна k = 0/1/2/3/5/10/25 из
опубликованных summary трёх экспериментов и считает площадь под кривой.

Источники (только их `results/summary/summary.json`, код не импортируется;
согласованность чекпойнта ассертится):

- k=0 — `2026-08-18_pretrain_smolvla_prompt_only` (канонический `true`);
- k=1/2/3 — `2026-08-18_pretrain_smolvla_few_shot_tune_low_k`;
- k=5/10/25 — `2026-08-18_pretrain_smolvla_naive_baseline_few_shot_tune`.

## Метрики AUC

Трапеция под success(k) на k ∈ [0, 25] по измеренным узлам, для среднего по
всем 10 задачам, по задачам 0–2 (задание) и по каждой задаче отдельно:

- `auc_raw` — сырая площадь (success × демо, максимум 25);
- `auc_normalized` (nAUC) — raw/25, средний success по диапазону при линейной
  интерполяции, шкала [0, 1];
- `auc_log2_normalized` — узлы по шкале log2(1+k): дешёвый режим k=1..3 весит
  столько же, сколько 3..25 — рекомендуемый headline-скаляр для сравнения
  методов адаптации («сдвиг кривой влево» одним числом).

## Запуск

```bash
scripts/build.sh          # или: analyst-curve-build (после uv sync)
pytest -q                 # тесты AUC-математики
```

Выходы: `results/summary/{summary.json,combined_curve.csv,combined_curve.png}`,
`reports/REPORT.md`.

Оговорки наследуются от источников: один сид обучения; k=0 оценивался под
претрен-нормализацией, k>0 — под статистиками target-демо.
