# Prompt-only v3: воспроизводимый пер-эпизодный шум политики

Дата: 2026-08-19. Переделка `2026-08-18_pretrain_smolvla_prompt_only_2` с
одним изменением протокола: **шум flow-сэмплинга политики сидируется в начале
каждого эпизода** (`noise_seed(e) = 1000 + e`, batch=1). Причина — открытие
из HARNESS_NOTE пробы 3: в `_2` шум действий шёл из глобального torch-потока
процесса, и исходы зависели от раскладки (task 4 true: 1/20 в раскладке `_2`
против 5/20 в свежем процессе при одинаковых сидах и init-состояниях).

Теперь каждый эпизод — детерминированная функция (чекпойнт, env-сид,
init-состояние, noise-сид): шум разный между эпизодами, но воспроизводимый в
любой раскладке. Перед полным прогоном обязательный determinism-смоук:
`true__task_4` дважды в разных раскладках процесса → поэпизодные исходы
обязаны совпасть.

Всё остальное как в `_2`: замороженный претрен (seen-контроль 20/20), все 10
задач libero_goal, условия true/wrong/nonsense (wrong = инструкция задачи
(id+1)%10), сиды 1000–1019, все 600 видео на диск, в Trackio — эпизод 0.
`_2` остаётся замороженным референсом; агрегация строит сравнение `_3` vs
`_2` по каждой ячейке.

## Запуск

```bash
cd experiments/2026-08-19_pretrain_smolvla_prompt_only_3
scripts/prepare.sh          # чекпойнт-манифест + LIBERO-конфиг
# determinism smoke (см. protocol.yaml), затем:
scripts/run_all.sh          # 30 точек (3 условия x 10 задач) на GPU 0-3
scripts/aggregate.sh        # таблицы, Wilson CI, сравнение с _2, график
```
