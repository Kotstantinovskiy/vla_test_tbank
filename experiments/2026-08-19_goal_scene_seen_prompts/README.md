# Goal-сцена × seen-промпты: обученные строки в незнакомой сцене

Дата: 2026-08-19. Диагностическая проба №3 — зеркало seen-проб: теперь
**сцена новая** (libero_goal, среда только для оценки), а строки — те, что
селектор знает дословно. Вопрос: вытягивает ли точная обученная строка свой
навык в незнакомой сцене, или сцена — связывающее ограничение zero-shot?

Наследует v2-машинерию (успех = предикат подсказанной задачи, эпизод
завершается по нему) и добавляет **поведенческие метрики** — минимальная
дистанция гриппера до объекта env-задачи и смещение этого объекта, — потому
что на полу (k=0 ≈ 0.005) бинарный success может не различать условия.

## Дизайн (13 точек × 20 эпизодов, замороженный претрен)

| Блок | Точек | Промпт | Вопрос |
|---|---|---|---|
| `true` | 5 | родная goal-инструкция | k=0 бейзлайн; якорь «turn on the stove» — сам по себе обученная строка (чистый эффект сцены) |
| `seen_twin` | 4 | дословная libero_90-строка того же навыка | решающие ячейки: спасает ли точная строка zero-shot |
| `seen_cross` | 2 | twin-строки двух bowl-задач, поменянные местами | instruction following в новой сцене (успех = предикат промпта) |
| `nonsense` | 2 | «perform the dax florp twice» | поведенческий контроль простоя |

Внутри env условия делят сиды/init-состояния → парный McNemar; блок `true`
обязан поэпизодно воспроизвести prompt_only (1/200, успех task 4 эпизод 4) —
встроенная проверка харнесса. Предсказания и правила R1p3–R4p3 записаны до
запуска: [reports/PRIOR_EXPECTATION.md](reports/PRIOR_EXPECTATION.md).

## Запуск

```bash
cd experiments/2026-08-19_goal_scene_seen_prompts
scripts/prepare.sh    # чекпойнт-манифест + план (env по тексту, twin-строки валидируются по libero_90)
scripts/run_all.sh    # оркестратор: 13 точек на GPU 0-3, все видео на диск
scripts/aggregate.sh  # таблицы, Wilson CI, парные McNemar, поведенческие метрики, график
```
