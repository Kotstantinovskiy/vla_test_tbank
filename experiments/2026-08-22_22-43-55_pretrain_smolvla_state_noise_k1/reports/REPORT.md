# Аугментация шумом проприоцепции при k=1 (полное обучение / full fine-tune)

Каждая адаптация (задача, альфа) представляет собой независимую полную тонкую настройку (full fine-tune) зафиксированной предобученной модели на официальной демонстрации demo_0 для данной задачи с добавлением аддитивного гауссовского шума с нулевым средним значением `alpha * eps`, который применяется к нормализованному проприоцептивному состоянию внутри метода policy.forward только во время обучения (состояние нормализовано методом MEAN_STD, поэтому альфа эквивалентна sigma_i = alpha * Std(s_i) в исходных единицах). Действия и изображения остаются без изменений; при оценке (n_action_steps=50, 20 эпизодов, набор начальных состояний/seed bank 1000..1019) шум не применяется. Альфа α=0.00 является контролем внутри эксперимента (строго пустая операция / no-op, рецепт full-FT k=1).
