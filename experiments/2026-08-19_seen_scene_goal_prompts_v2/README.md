# Seen-сцены × goal-промпты v2: успех = предикат подсказанной задачи

Дата: 2026-08-19. Повтор пробы №1 с тремя изменениями (по запросу):

1. **Успех переопределён**: первичная метрика — выполнен ли goal-предикат
   *подсказанной* задачи (парсится из её BDDL и вычисляется на каждом шаге в
   живой сцене; эпизод завершается и по нему). Предикат env-задачи остаётся
   вторичной, v1-сравнимой метрикой. Это превращает качественное «на видео
   модель выполняет подсказанную задачу» из v1 в число (instruction-following
   accuracy) — прежде всего для блока `cross`.
2. **Новый срез `goal`**: все 10 инструкций libero_goal; каждая, чей предикат
   вычислим в какой-то seen-сцене, получает точку (host: verbatim-trained env
   → env парафразной пары → минимальный вычислимый env_task_id). Голы 1/2/5/6
   невычислимы ни в одной из 90 сцен (миска+плита не сосуществуют и т.п.) —
   зафиксированы как skipped.
3. **Блок `absent` удалён** (по решению пользователя; skipped-строки среза
   документируют ту же информацию статически, без роллаутов).

Замороженный чекпойнт претрена тот же, что в v1; сиды/init-состояния те же →
trained/paraphrase точки обязаны воспроизвести v1 бит-в-бит (это встроенная
проверка реплея). Для точек, где предикат промпта совпадает с предикатом env,
дополнительно ассертится пошаговое согласие внешнего вычисления предиката с
`env.check_success()`.

## Дизайн (16 точек × 20 эпизодов)

| Блок | Точек | Первичная метрика |
|---|---|---|
| `trained` | 7 | предикат env (= предикат промпта) |
| `paraphrase` | 4 | предикат goal-задачи |
| `cross` | 2 | предикат задачи-партнёра (**instruction following**) |
| `goal` | 1 новая (+5 алиасов, 4 skipped) | предикат goal-задачи |
| `nonsense` | 2 | только env-метрика (предиката нет) |

Предсказания и правила R1v2–R4v2 записаны до запуска:
[reports/PRIOR_EXPECTATION.md](reports/PRIOR_EXPECTATION.md).

## Запуск

```bash
cd experiments/2026-08-19_seen_scene_goal_prompts_v2
scripts/prepare.sh    # чекпойнт-манифест + план (env по тексту, предикаты из BDDL)

scripts/aggregate.sh  # таблицы, Wilson CI, парные McNemar, goal-срез, график
```

## Результаты (2026-08-19, 320/320 эпизодов, 0 расхождений предикатов)

**Instruction following почти идеален для обученных строк**: в cross-блоке
модель выполняет подсказанную задачу на уровне её native rate — «поставь
сковороду» в env плиты **17/20** (native 16/20), «включи плиту» в env
сковороды **20/20** (native 20/20); env-метрика при этом 0/20, как в v1.
Сработало правило **R1v2**: v1-обвал cross был свойством метрики, а не
политики; язык каузально и чисто выбирает навык. Novel-строка goal-0 («open
the middle drawer…», нигде не обучалась): по своему предикату **0/20**
(exact-string модель устояла, R3v2 не сработало), но env-метрика **15/20** —
откат к обученному навыку сцены под родственной, хоть и новой строкой (при
nonsense — 0/20): деградация ступенчатая. Все 14 общих с v1 точек
воспроизведены поэпизодно точно. Вердикт: [reports/FINDINGS.md](reports/FINDINGS.md).
